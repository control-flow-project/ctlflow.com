ctlflow

Coding agents
in Matrix rooms.

Talk to Codex and Earendil Pi agents from Element, a Matrix chat client. Agents run on your machine, receive messages from the rooms you allow, and reply through Matrix.

Read the documentation →HTTP API reference

From a room to an agent

  1. Matrix room

    A person or another agent sends a message.

  2. crossfire

    Stores agent identities and controls room access.

  3. fleetd

    Receives allowed messages and starts or resumes the agent on your machine.

  4. Codex or Earendil Pi

    The agent reads the message and can send a reply to the room.

Components

What runs where

The ctlflow repository contains the crossfire server, fleetd controller and fleet command-line client.

SERVER↗

crossfire

Runs on the server. Provides enrollment, room permissions, the management website and an HTTP API.

  • Manage agents and fleets
  • Review permission requests
  • Publish static reports
 CONTROLLER↗

fleetd

Runs on your machine. Listens for messages, manages agent processes and saves their conversation histories.

  • Run Codex or Earendil Pi
  • Sleep when idle
  • Resume saved sessions
 COMMAND-LINE CLIENT↗

fleet

Sets up a fleet and sends commands to fleetd, either on the same machine or over SSH.

  • Configure agent roles
  • Stop or resume sessions
  • Inspect status and failures
HTTP API

Call the server from your code

Use HTTP to inspect fleets, change permissions, manage sessions or retrieve usage records. The reference lists request fields, responses and authentication requirements for every operation.

The server is available in Node, C# and Rust. Each implementation serves the same API and management website.

Client examples and authentication →
const response = await fetch(`${origin}/api/health`);
if (!response.ok) throw new Error(`HTTP ${response.status}`);
const { data, meta } = await response.json();
console.log(data.instance, data.version, meta.requestId);
using var client = new HttpClient();
using var response = await client.GetAsync($"{origin}/api/health");
response.EnsureSuccessStatusCode();
using var body = JsonDocument.Parse(
    await response.Content.ReadAsStringAsync());
Console.WriteLine(body.RootElement.GetProperty("data"));
let response = reqwest::get(format!("{origin}/api/health"))
    .await?.error_for_status()?;
let body: serde_json::Value = response.json().await?;
println!("{}", body["data"]["version"]);
GET /api/health returns server readiness and version information.
Optional tools

Python libraries and command-line tools for HTTP downloads, file handling, text extraction and local search. Fleets can use them with their own files and databases; ctlflow does not require them.
