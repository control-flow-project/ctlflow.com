## Review corrections

- Source imports read immutable Git bytes, not dirty working-tree data attributed
  to another commit.
- Schema anchors preserve exact identifier case.
- Removed/unrecorded output, edited generated pages and symlink escapes fail
  before destructive reconciliation.
- Supplied unresolved bounds/choices fail instead of becoming silent defaults.
- Private fleetd request limits, native Matrix pagination and binary publication
  input are documented separately from server REST defaults.
- Product names, ownership, implementation choices and optional Toolsmith usage
  follow the ctlflow hierarchy. No private fleet material is imported.

## Limits and deployment

No Netlify project, DNS, account or production instance was changed. Connect the
repository using the checked-in `netlify.toml` to activate hosting.
Website checks do not certify product runtime parity, SQLite migrations, provider
behavior, package publication or production deployments. Those retain their
product-owned gates. Product LICENSE links remain authoritative; a separate
unmerged licensing branch does not change this documentation's pinned source.

The ten-agent London-theatre `fleet-street` sample and its documentation are
queued separately. This website does not claim that unfinished example exists.
